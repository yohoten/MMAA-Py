## 使用约定

1. **只读**：不修改源码与文档；需要试验时复制到 `../modelit/` 或临时目录。
2. **不引用为依赖**：不在 notebook 中 `import` 这里的模块，也不把 `.m` 文件当作文档链接来源。
3. **可运行性未知**：MATLAB 版本、编译器、依赖库均未标注；`.c` 代码需要自行配置构建环境。
4. **版权**：源码与课件的著作权归原作者/出版方，仅作学习参考，不随仓库 MIT 授权发布。
5. **体积**：超过 5 MB 的文件（`.pdf` 49 个、`.ppt` 37 个）入库需走 Git LFS，规则见仓库根 `.gitattributes`。
