## 运行方式

1. Python 3.10 或 3.11（`pyproject.toml` 约束），依赖见仓库根 `requirements.txt`。
2. 内核工作目录必须是本目录（JupyterLab / VS Code 默认如此），notebook 里的 `../data/xxx` 才能解析。
3. 首次运行前确认 `../data/` 下对应文件存在；下表“数据”列标注了缺失项。
4. 修改后必须 `Kernel → Restart & Run All` 再保存，执行计数应从 1 连续递增。

## 类型说明

- **实验型（多数）**：问题背景 → 学习目标 → 环境与数据 → 方法与实现 → 小结，含可运行代码。
- **讲义型（23、24）**：只含 Markdown 正文，无代码单元，编号仍在序列内以便与教材章节对照。
- **占位稿（29）**：仅保留标题、元信息与待补充说明；引用该编号时请注明“未完成”。
- **融合篇（31—43）**：由教材练习稿按主题整理；35、37、38 的原文代码较少，其余均含可运行示例（32 含整数规划与目标规划示例）。均未执行，首次运行前先看各篇“环境与数据”。

## 新增或修改 notebook 的检查清单

1. 文件名 `NN.主题.ipynb`，两位序号、半角句点、末尾无空格；序号不重复。
2. 一级标题 `# NN 主题`；顶部一行元信息 `> **模块**：… ｜ **数据**：… ｜ **依赖**：…`。
3. 数据只从 `../data/` 读取，不写盘符路径；产生的图表写入 `output/`（已忽略）。
4. 图片用 `![](../data/images/xxx.png)`，禁止 `attachment:`。
5. 依赖若不在 `pyproject.toml` 中，先补声明再提交（检查器 R014 会拦截）。
6. 运行 `python ../scripts/check_project.py`，确保未新增 ERROR。
