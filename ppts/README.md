## 与其他目录的关系

- `ppts/` 按**工具链 → 方法**组织，前 4 章是 Python 基础，与教材章节顺序不同；教材正文在 [`../docs/`](../docs/)。
- 方法类课件（09—18）与 [`../notebooks/`](../notebooks/) 的编号并非一一对应，按主题检索更可靠：综合评价对应 01—02、40，图论对应 03—06、28，多元分析与回归对应 07—12、23、37—38，插值与拟合对应 34，微分方程对应 41，智能算法对应 39，时间序列对应 20—22、24、27、29—30，SVM 对应 36。
- 课件中的 MATLAB 示例可与 [`../manual/`](../manual/) 的源码对照。

## 使用约定

1. 只读：不改写原文件；需要标注时新建 Markdown 笔记。
2. 引用时写清“课件第 NN 章 + 页码”，不复制整页截图进 notebook。
3. 不把课件内容当作代码依赖；示例代码需在 notebook 或 `modelit/` 中重写后再运行。
4. 新增课件按 `NN_章节名.pptx` 命名，两位数序号；分册用 `-1` / `-2` 后缀。
