## 使用约定

1. **不修改原文件**：需要标注时另建 Markdown 笔记，不覆盖 PDF / PPT。
2. **不复制进 notebook**：引用教材结论时写清章号与页码，不把 PDF 截图当作 `attachment:` 内嵌。
3. **链接用相对路径**：从本文件引用其他目录时写 `../notebooks/…`、`../ppts/…`。
4. **新增资料先查重**：`docs/` 与 `manual/` 存在同主题的 PDF/PPT 副本，入库前先确认是否已有同内容文件。
5. **体积控制**：单文件超过 5 MB 的 PDF/PPT 需走 Git LFS（规则见仓库根 `.gitattributes`）。
