## 使用约定

- 只读：不覆盖、不改名、不在原文件上追加列；派生数据写到案例 `output/`。
- `data/textbook/` 下的 10 个 `.txt` 是教材参考实现的输入，已随融合并入本目录；代码内统一写 `../data/textbook/文件名`。
- 路径：notebook 内统一 `../data/文件名`（教材数据为 `../data/textbook/文件名`），禁止盘符路径与 `data/` 开头的根相对写法。
- 编码：CSV 若含中文，读写时显式指定 `encoding="utf-8"` 或 `"gbk"`，不要依赖系统默认。
- 大文件：`bitcoin_data.csv` 与 `Online_Retail.xlsx` 合计约 94 MB，入库需走 Git LFS（规则见仓库根 `.gitattributes`）；若改为下载脚本，请附 SHA-256 校验和。

## 新增数据的要求

1. 可公开再分发，或明确标注“仅本地使用，不入库”。
2. 单文件建议小于 5 MB；超过则走 LFS 或提供下载脚本。
3. 在本文件的清单表中补一行：文件、体积、引用方、用途。
4. 同步更新引用它的 notebook 顶部元信息（`**数据**：` 字段）。
5. 运行 `python scripts/check_project.py` 确认路径检查通过。
